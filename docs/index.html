실제 공장의 복잡성을 시뮬레이션으로 재현하고, 그 위에서 LLM이 디스패칭 규칙(우선순위 함수)을 세대를 거쳐 진화시켜 사람이 손으로 만든 고전 휴리스틱과 비교합니다.

현실 공장이 프로젝트
주문 → 여러 공정 순서작업(job) → 공정(operation)
공정마다 가능한 설비가 다름유연성 = 공정당 사용 가능 기계 수 (JSSP↔FJSSP)
고객 납기 / 지연 비용납기일 / 평균 지연(AT) 지표
부품 입고 지연 · 긴급 주문교란 시나리오 S1 · S2
현장의 "다음에 뭘 할지" 결정디스패칭 규칙(우선순위 함수)
전문가가 수개월 튜닝LLM이 분 단위로 규칙 진화
